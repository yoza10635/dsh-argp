# 06c 三臂本地成本对比报告（35B·22K 窗口）

- 模型：`Qwen3.6-35B-A3B`（本地 llama.cpp, 8080/v1, 256K ctx, Q4_K）
- harness：`spike/06c-realistic-coding.ts`（三臂：A=ArgpGraphEngine / B=BasicCompactionEngine / C=B+recall_search 关键词召回）
- 参数：`ARGP_WINDOW_TOKENS=22000 / ARGP_RETAIN_TOKENS=6000 / ARGP_MAX_TURNS=15 / ARGP_CONTEXT_WINDOW=262144`
- 产物：`spike/out/06c-35b-A-2026-08-24T02-11-26-632Z`、`06c-35b-B-...02-16-04-152Z`、`06c-35b-C-...02-19-59-222Z`
- 成本仪表：`spike/compare-cost.mjs`（双锚 + 分量支配检查 + 质量轴）

## 2. 相对 ARGP 臂（A）的成本比

| 锚 | A vs B | A vs C |
|---|---|---|
| v4-flash | B = 102.7% of A（A 便宜 2.7%） | C = 94.5% of A（**A 贵 5.5%**） |
| M3 | B = 158.9% of A（A 便宜 37%） | C = 146.7% of A（A 便宜 32%） |

→ 排名**跨锚翻转**：
- v4-flash（价差 30×）：C < A < B（ARGP 居中，比摘要基线 B 便宜、比关键词召回基线 C 贵）
- M3（价差 5×）：A < C < B（ARGP 最便宜）

## 3. 分量支配检查（价格结构无关性）

| 对比 | miss | hit | out | 结论 |
|---|---|---|---|---|
| A vs B | A > B ⚠️ | A ≤ B | A > B ⚠️ | 存在反超 ⚠️（排名依赖锚） |
| A vs C | A > C ⚠️ | A ≤ C | A > C ⚠️ | 存在反超 ⚠️（排名依赖锚） |

ARGP 在 (miss, hit, out) 三分量上**不全面支配**任一基线：其 hit 更低（压缩打掉前缀缓存），但 miss 与 out 都更高。故成本结论**依赖价格向量**，非结构无关。

## 4. 质量轴（模型绑定，仅展示）

| 臂 | 压缩 | pruneTx | shadowed | recallCalls | U正确 | R正确 | 失败项 |
|---|---|---|---|---|---|---|---|
| A | 5 | 5 | 29 | 1 | 1 | 0 | 1 |
| B | 0 | 0 | 0 | 0 | 1 | 1 | 0 |
| C | 0 | 0 | 0 | 1 | 1 | 1 | 0 |

- A：`L3-r-recovery` 0/1（35B 下 1 次 recall 调用被判不正确）—— 模型绑定质量，与 v4-flash 正式档 R 7/7 形成对照，印证 recall 服从是模型属性。
- B/C：trivially PASS（未剪枝，U/R 找回 N/A 或 grep 直取）。

## 5. 解读

### 5.1 为何 ARGP 在此场景不结构胜出
- 22K 小窗口下 surface 仅 25–27K，A 每次压缩只剪掉少量上下文，但**每次压缩把 system 前缀打掉一次**（固定 ~25K 击穿惩罚），5 次 ≈ 125K 额外 miss。
- 剪枝省下的 miss ≪ 缓存击穿的固定代价 → 在 miss/hit 价差大的 v4-flash（30×）下几乎打平，价差小的 M3（5×）下才明显胜。
- 这与 memory 已记的固有权衡一致（"压缩本身必丢一次缓存"）；也与 160K 定稿（ARGP ¥2.695 vs 基线 ¥3.087）不矛盾——那时剪掉 32K 量级，剪枝收益碾压固定击穿代价。

### 5.2 方法论红旗（对比公平性）
B/C 臂的 `BasicCompactionEngine` 在此 06c 合成驱动里**实际 0 次压缩**（触发线口径=22K 同 A，但 `TokenMeter` 压力通道在合成循环中未点火）。故本次是 **"ARGP 主动压" vs "基线不压"**，并非 "ARGP vs 摘要式基线"。要得到公平 3 臂，需修复 B/C 压缩接线或换能驱动它的场景。

### 5.3 对原问题"本地模型能否替代成本对比"的回答
- ✅ 能：测 token 流 (miss/hit/out)、验证成本仪表、暴露价格结构依赖与缓存击穿权衡。
- ⚠️ 但不能在此尺度复现 ARGP 的**结构胜势**：小窗口 + B/C 未压，使得本地跑只能证明"ARGP 压了也不比不压贵多少 / 在窄价差锚下更省"。**决定性成本胜势仍在 160K v4-flash 正式档**（¥2.695 vs ¥3.087）。
