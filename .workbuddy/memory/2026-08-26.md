## D 臂（第四臂·dsh 原生摘要压缩基线）补跑 2026-08-26T16

### 背景
P5 三臂 GO 后用户拍板补跑"传统 LLM 摘要压缩"对照（用乙方案 = dsh 原生 `BasicCompactionEngine`，安装 argp 时经 cordis.yml 被 disable）。目的：回答"既然摘要更便宜为何还要 ARGP"。

### 装配要点（spike/37-peratom-three-arm.ts 加 8 处）
1. `BasicCompactionEngine` **硬依赖 `ctx.tokenMeter`**（dsh-compaction-basic lib/index.js L743 `static inject=["tokenMeter",...]`）→ 加 `import TokenMeter` + `await ctx.plugin(TokenMeter)`（放 AgentLoop 前，对 A/B/C 无害）。缺则压力通道静默 no-op，压缩不触发。
2. 阈值换算：`thresholdRatio=WINDOW_TOKENS/CONTEXT_WINDOW=16000/20000=0.8`→thresholdTokens=16000；`retainTokens=4000`；`auto:true`。不显式设 summarizationModel 则继承会话模型（本地 Qwen）。
3. **成本口径陷阱**：harness `turnStats` 仅从 `assistant/message` 取 usage（line 353），引擎内 `summarize()` LLM 调用不计入主成本 → 新增 `allLlmCost` 遍历全部 session 事件、兼容 dsh `inputTokens` 与 openai `prompt_tokens` 两种格式。实测 D 全口径 ¥0.134 vs 主 ¥0.1235，差额 ¥0.0105=摘要开销，捕获成功。
4. 换代轮基于 `replaceGeneration` 增量（D 摘要替换同样顶缓存）；`engine.records` 对 D 不存在用 `?.` 得 0。
5. D 防干涉判据设计使然跳过：`if (ARM!=='D')` 跳过 `P5-originals` 判决，打 `[SKIP P5-originals]`（摘要改写历史属预期，originals 零替换测量不反映语义损失）。

### 结果（30 轮，单 slot 串行，同任务同模型）
- 30/30 PASS，summaryCompactions=1（仅 T16-mod9），genBumpTurns=['T16-mod9']，recall/zoom=0，maxSustainedTurns=30，verdict failures=[]。
- 探针 **5/7**：D1-D4 跨轮精确依赖 4/4 全对；**G1(gist 大意) MISS + R2(精确找回被剪 artifact ART-11-MARKER-1D4T) MISS** = 摘要吞掉信息。
- 成本：¥0.124 主 / **¥0.134 全口径**；miss 59.8k/hit 314k/out 4.0k；命中 84%（历史压短致命中高但语义已损）。
- 四臂对照（v4-flash 空闲锚）：A ¥0.454 7/7 / B ¥0.556 7/7 / C ¥0.802 6/7(R2✗) / **D ¥0.134 5/7**。

### 校准结论（核心卖点）
传统摘要 D 最便宜（比 C 5.98×、比 A 3.39×），但丢精确 token+大意。ARGP 双引擎用"图拓扑纯算法剪枝+per-atom recall/zoom"替代"LLM 重写历史"，做到 7/7 保真且仍比 C 便宜 1.77×。**战略卖点=保真前提下最省，非最便宜**：四臂唯一同时 7/7+比 C 便宜的是 A；D 只赢成本、C 既贵又丢 R2。
