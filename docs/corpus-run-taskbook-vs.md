### 2.1 这些常量真的进承重词表了吗（**已实测**，勿凭假设）

用 `findLoadBearingTokens` 逐条验证（2026-09-15）：

- **ALL_CAPS 常量：名字本身就命中**，与值无关 ——
  `CANVAS_W=960` → `["CANVAS_W","CANVAS_W=960"]` 双命中；
  `TIER_LEGENDARY_WEIGHT=3` → 命中 `TIER_LEGENDARY_WEIGHT`（值 `3` 只有 1 字符，`key=value`
  规则要求值 ≥2 字符，**但名字靠 ALL_CAPS 兜住了**）。故 §2 表里的 ALL_CAPS 项**全部安全**。
- **小写 `keyword=value` 需要值 ≥2 字符**：
  | 写法 | 识别 |
  |---|---|
  | `dmg_flat=5` | **✘ 完全不识别** |
  | `dmg_flat=5.0` | ✔ |
  | `max_hp=2` | **✘** |
  | `max_hp=20` | ✔ |
  | `crit_chance=0.05` / `atk_speed=0.1` / `dmg_mult=0.15` | ✔ |
- **裸小写标识符不识别**：`dmg_flat`（不带 `=`）→ ✘。所以 7 个关键字只有在**配置文件里以
  `key=value` 形态出现**时才承重；在对话正文里列它们不算。
- **路径天然承重**：`src/systems/spatial-grid.js:88` → 同时命中路径与 `file:line` 两个 token。

**因此的书写纪律**（不是"凑 token"，是现实写法）：配置里数值一律带小数或至少两位
（`dmg_flat=5.0` / `max_hp=20` / `crit_chance=0.05`）——伤害/概率本来就是小数，无需为语料扭曲任务。
**反过来说**：这些锚点服务于**探针**（探针只需要"信息落在旧原子"，不依赖承重性）；
承重性是**额外**把锚点与 HLS / 保真守卫 / 推断边耦合起来的好处，**不要为了凑承重 token 改造任务**。
